# Scientific supporting artwork
Built-in image_gen generated the three raster assets, 1672×941 pixels, then optimized
as local WebP (quality 82). AI artwork is conceptual, not a measured activation map.

- `neuroscience/neuroai-hero.webp`: anatomically inspired brain on navy; header artwork.
- `neuroscience/ai-neuroscience-bridge.webp`: brain → signals → data → model → insight.
- `neuroscience/neural-network-background.webp`: restrained biological neural texture.
- `backgrounds/eeg-wave-background.svg`: deterministic abstract waveform accent.
- `branding/neuroai-mark.svg`: original line/circuit brain motif, authored as SVG.
- `icons/empty-*.svg`: consistent minimal empty-state icons.

No hotlinked imagery or stock photos. Originals are retained outside the application
at `/Users/morganbrown/neuroai-artwork/`. Replace files at the same paths to update art.
Raster prompts are recorded in `generation-prompts.json`. Charts remain code-driven.
